# Maurice Trading AI

Maurice Trading AI is a web-based application built with React, designed to help users receive binary prediction signals, manage bots, and provide admin-level control over trading features.

## Features

- **Market Predictions Panel**: Displays real-time predictions (Rise/Fall) with confidence levels.
- **Admin Dashboard**:
  - Upload trading bots from files.
  - Build new bots directly from the interface.
  - Approve or reject user-submitted bots.
- **Firebase Auth (Placeholder)**: Firebase setup included for secure login (requires your Firebase config).
- **Mobile Friendly**: Designed to run smoothly on mobile browsers and Android web apps.
